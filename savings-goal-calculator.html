How to Use This Calculator

  1. Set a Savings Target — the total amount you want to save (house, emergency fund, vacation).
  2. Enter Current Savings — how much you have already set aside.
  3. Enter Monthly Contribution — how much you can consistently put away each month.
  4. Set an Interest Rate — 4-5% for HYSA, or 0% for cash.
  5. Click Calculate — see exactly how long until you hit your target.

Example: Saving for a Home Down Payment

You want to save $50,000 for a down payment. You have $5,000 saved and can contribute $500/month at 5% interest.

🏠 The Timeline

  • Time to goal: ~6 years 2 months
  • Total contributions: ~$42,000
  • Interest earned: ~$8,216
  • If you increase to $750/month: ~4 years 5 months

Common Mistakes

❌ Setting unrealistic contributions. Use a number you have consistently hit for 3+ months.

❌ Forgetting inflation. A $50,000 goal today may need about $63,300 in 8 years at 3% inflation.

❌ Ignoring rate changes. HYSA rates change. Use a conservative estimate.

Frequently Asked Questions

How much should I save each month?▼
The 50/30/20 rule suggests saving 20% of after-tax income. Start with 5-10% and increase gradually.
Where should I keep my savings?▼
Short-term (under 5 years): high-yield savings account. Long-term (5+ years): brokerage with index funds.
What goal should I start with?▼
Start with a $1,000 emergency fund, then 3-6 months expenses. Then specific goals: down payment, car, vacation.
